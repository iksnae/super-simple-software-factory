# Learn the Khaos Machine Workspace

Follow `AGENTS.md`; it governs this skill and every other instruction used in
the workspace.

## Orientation

1. Read `SOUL.md`, `AGENTS.md`, `USER.md`, `CURRENT.md`, and `MEMORY.md` in
   their documented order.
2. Read `WORKSPACE.md` before inspecting unfamiliar paths and
   `docs/VISION.md` before describing components or maturity.
3. Load `README.md`, `ARCHITECTURE.md`, `GLOSSARY.md`, and other routed
   documents only when the requested orientation requires their topic.
4. Inspect source files only within the scope needed to answer the request.
   Do not read every source file merely because the user asked for general
   orientation.

An explicit request to read every source file broadens the scope and may use
an exhaustive source pass. It does not change workspace boundaries,
concurrent-agent precautions, or the document precedence in `AGENTS.md`.

Report only claims supported by files actually read, citing `file:line` or
quoting the governing clause inline. Label anything else **unverified**.
